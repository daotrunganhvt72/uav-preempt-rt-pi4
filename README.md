# Scheduling Analysis of UAV Flight Control Workloads on PREEMPT_RT Linux

Replication on Raspberry Pi 4 with 4 GB RAM.

Website: https://daotrunganhvt72.github.io/uav-preempt-rt-pi4/

Chuyên đề tiếng Việt dựa trên báo cáo dự án tháng 10/2026, gồm sơ đồ kiến trúc, mô hình deadline tương tác, dữ liệu tham khảo Pi 5 và lộ trình M0–M6.

Báo cáo chưa có dữ liệu đo trên Pi 4. Số liệu Pi 5 là dữ liệu tham khảo; slider deadline chỉ minh họa khái niệm.

Website tĩnh, không cần build. GitHub Pages phục vụ nhánh main, thư mục gốc. Mở index.html hoặc phục vụ thư mục bằng HTTP để xem trên máy.

Typography: IBM Plex Serif, Source Sans 3 và Roboto Mono qua Google Fonts, có font dự phòng.
